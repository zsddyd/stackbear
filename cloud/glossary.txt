# ASR glossary: "wrong => right", applied to every transcript after recognition.

# A recogniser trained on general speech mishears the words one person actually
# uses: colleague names, product names, internal jargon. Add them here and they
# are corrected in every transcript, whichever engine produced it. Rules are
# applied longest-first and a replacement is never rescanned, so a short rule
# cannot damage a longer match. The file is read per transcription.
#
# Format: one rule per line, "wrong => right". Lines starting with # are ignored.
# An all-ASCII wrong-form needs ASCII word boundaries, so a product code cannot
# corrupt a longer Latin word (LE matches "对LE的" but not "LEVEL").
#
